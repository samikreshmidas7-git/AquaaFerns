# AquaaFerns Inventory Management

This project uses the MERN stack (MongoDB, Express, React, Node.js) for inventory management. The UI will be mobile-friendly and support authentication for admin and customer roles.

## Structure
- `frontend/` - React app for UI
- `backend/` - Node.js/Express API

## Pages to be built
- Home (Blog)
- Catalogue (Product List)
- Login
- Dashboard (Sales & Overview)
- Product Entry
- Sales Entry
- Damage Entry

## Authentication
- Admin: Access to all pages
- Customer: Access to catalogue only

---
Designs will be provided by the user. UI development will start first.
